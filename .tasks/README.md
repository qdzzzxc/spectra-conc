# Задачи для исполнителя (opencode + локальная модель)

Каждая задача — файл `NNN-<slug>.md`. Запуск (из корня проекта):

```bash
opencode run "Выполни задачу из приложенного файла строго по плану. Сначала прочитай .tasks/README.md." \
  --title task-NNN -f .tasks/README.md -f .tasks/NNN-<slug>.md
```

Права исполнителя задаёт `opencode.json` в корне: правка файлов, `uv run pytest`, `uv run python scripts/*`, чтение git; остальное запрещено.

## Правила для исполнителя (обязательны в каждой задаче)
1. Меняй только файлы из списка задачи. Новые файлы — только если они перечислены.
2. Если для выполнения плана нужно изменить файл не из списка или план противоречит коду/тестам — **остановись** и напиши в отчёте: что именно противоречит и какой файл нужно поменять. Не обходи ограничение.
3. Не добавляй отладочные print, временные файлы, хуки. Если тест падает и причина не очевидна за 2 попытки — остановись и опиши ошибку в отчёте.
4. Не делай git commit, не меняй `pyproject.toml`/`uv.lock`, не ставь пакеты.
5. В конце — отчёт: изменённые файлы, вывод команд приёмки, отклонения от плана (если были).
