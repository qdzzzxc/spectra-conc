## 1. `src/spectra/nn.py`
Docstring модуля: «Нейросетевые модели на torch (CPU) с интерфейсом sklearn. Требуют группу зависимостей nn: uv sync --group nn.»
Импорты: `numpy as np`, `torch`, `from torch import nn`, `from sklearn.base import BaseEstimator, RegressorMixin`.

### 1.1. Функция сети
```python
def _make_net(n_filters: int, kernel_size: int, hidden: int, dropout: float) -> nn.Sequential:
    """AvgPool(4) -> [Conv1d -> ReLU -> AvgPool(4)] x 2 -> Flatten -> Dropout -> Linear(hidden) -> ReLU -> Linear(1).
    Первый AvgPool(4) усредняет соседние каналы: спектр передискретизирован, а обучение на CPU в 4 раза быстрее."""
    pad = kernel_size // 2
    return nn.Sequential(
        nn.AvgPool1d(4),
        nn.Conv1d(1, n_filters, kernel_size, padding=pad), nn.ReLU(), nn.AvgPool1d(4),
        nn.Conv1d(n_filters, n_filters, kernel_size, padding=pad), nn.ReLU(), nn.AvgPool1d(4),
        nn.Flatten(), nn.Dropout(dropout), nn.LazyLinear(hidden), nn.ReLU(), nn.Linear(hidden, 1),
    )
```

### 1.2. Класс `CNN1DRegressor(BaseEstimator, RegressorMixin)`
Docstring: «1D-CNN по спектру. Вход центрируется средним спектром train и делится на общий std (одно число); y стандартизуется. Аугментация (только при обучении): случайные смещение, наклон базовой линии, шум и сдвиг по оси на ±shift_max каналов.»

`__init__(self, n_filters=8, kernel_size=9, hidden=32, dropout=0.1, lr=1e-3, weight_decay=1e-4, epochs=200, batch_size=64, augment=True, offset_std=0.1, slope_std=0.1, noise_std=0.02, shift_max=2, random_state=0)` — только присваивания `self.<имя> = <имя>` (правило sklearn, иначе `clone` сломается).

`fit(self, X, y)`:
1. `torch.manual_seed(self.random_state)`; `rng = np.random.default_rng(self.random_state)`.
2. `X = np.asarray(X, np.float32)`, `y = np.asarray(y, np.float32).ravel()`.
3. `self.x_mean_ = X.mean(0)`; `Xc = X - self.x_mean_`; `self.x_scale_ = float(Xc.std()) or 1.0`; `Xn = Xc / self.x_scale_`.
4. `self.y_mean_ = float(y.mean())`; `self.y_scale_ = float(y.std()) or 1.0`; `yn = (y - self.y_mean_) / self.y_scale_`.
5. `self.net_ = _make_net(...)`; один прогон `self.net_(torch.zeros(1, 1, X.shape[1]))` (инициализирует `LazyLinear`); `opt = torch.optim.AdamW(self.net_.parameters(), lr=self.lr, weight_decay=self.weight_decay)`.
6. `Xt = torch.from_numpy(Xn).unsqueeze(1)` (форма `(n, 1, p)`), `yt = torch.from_numpy(yn)`; `self.net_.train()`.
7. Цикл по `epochs`: `perm = rng.permutation(n)`; по батчам `idx = perm[i:i + batch_size]`:
   - `xb = Xt[idx]`; если `self.augment`: `xb = self._augment(xb, rng)`;
   - `loss = torch.mean((self.net_(xb).squeeze(1) - yt[idx]) ** 2)`; `opt.zero_grad()`; `loss.backward()`; `opt.step()`.
8. `self.n_features_in_ = X.shape[1]`; `return self`.

`_augment(self, xb: torch.Tensor, rng: np.random.Generator) -> torch.Tensor`:
- `b, _, p = xb.shape`; `t = torch.linspace(-1, 1, p)`;
- `offset = torch.from_numpy(rng.normal(0, self.offset_std, (b, 1, 1)).astype(np.float32))`;
- `slope = torch.from_numpy(rng.normal(0, self.slope_std, (b, 1, 1)).astype(np.float32))`;
- `noise = torch.from_numpy(rng.normal(0, self.noise_std, (b, 1, p)).astype(np.float32))`;
- `out = xb + offset + slope * t + noise`;
- если `self.shift_max > 0`: `s = int(rng.integers(-self.shift_max, self.shift_max + 1))`; `out = torch.roll(out, s, dims=2)` (один сдвиг на батч);
- `return out`.

`predict(self, X)`:
- `Xn = (np.asarray(X, np.float32) - self.x_mean_) / self.x_scale_`;
- `self.net_.eval()`; под `torch.no_grad()`: `p = self.net_(torch.from_numpy(Xn).unsqueeze(1)).squeeze(1).numpy()`;
- `return p.astype(float) * self.y_scale_ + self.y_mean_`.
