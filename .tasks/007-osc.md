# Задача 007: предобработка OSC — удаление направлений спектра, не связанных с концентрацией

## Зачем
В NTNU главная вариация спектров — температура (PC1 = 97%), а не глюкоза. Идея (упрощённый OSC/EPO): на train найти главные направления той части спектров, которая **не** объясняется концентрацией `y`, и вычесть проекцию на них из всех спектров. Это предобработка с обучением на `(X, y)` — как MSC, только ей нужен `y`. `sklearn.Pipeline` сам передаёт `y` в `fit` каждого шага, поэтому утечки нет: внутри вложенной CV `fit` видит только train.

## 1. `src/spectra/preprocess.py`
### 1.1. Класс `OSC` (поставить сразу после класса `MSC`)
```python
class OSC(BaseEstimator, TransformerMixin):
    """Упрощённый OSC/EPO: убрать k главных направлений вариации X, ортогональной y (по train).
    Остаток R = Xc − yc·wᵀ, где w = Xcᵀyc / (ycᵀyc); направления — первые k правых сингулярных векторов R."""
    def __init__(self, n_components=1):
        self.n_components = n_components
```
- `fit(self, X, y=None)`:
  - если `y is None` → `raise ValueError("OSC требует y в fit")`;
  - `X = np.asarray(X, float)`, `y = np.asarray(y, float).ravel()`;
  - `self.mean_ = X.mean(0)`; `Xc = X - self.mean_`; `yc = y - y.mean()`;
  - `w = Xc.T @ yc / (yc @ yc + 1e-12)`;
  - `R = Xc - np.outer(yc, w)`;
  - `_, _, Vt = np.linalg.svd(R, full_matrices=False)`;
  - `k = min(self.n_components, Vt.shape[0])`; `self.components_ = Vt[:k]` (форма `(k, n_features)`);
  - `self.n_features_in_ = X.shape[1]`; `return self`.
- `transform(self, X)`:
  - `X = np.asarray(X, float)`; `Xc = X - self.mean_`;
  - `return X - (Xc @ self.components_.T) @ self.components_`.

## 2. `tests/test_preprocess.py` — добавить тесты
Импорты дополнить: `OSC` из `spectra.preprocess`, `nested_group_cv` из `spectra.evaluate`, `regression_metrics` из `spectra.metrics`.
Данные: `ds = make_synthetic(n_solutions=20, seed=4)`.
1. `test_osc_components`: `o = OSC(2).fit(ds.X, ds.y)`; `o.components_.shape == (2, ds.X.shape[1])`; строки ортонормированы: `np.allclose(o.components_ @ o.components_.T, np.eye(2))`.
2. `test_osc_removes_directions`: `Xt = o.transform(ds.X)`; `np.allclose((Xt - o.mean_) @ o.components_.T, 0, atol=1e-8)`.
3. `test_osc_needs_y`: `pytest.raises(ValueError)` для `OSC(1).fit(ds.X)`; `pytest.raises(ValueError)` для `get_preprocessor("osc0")`.
