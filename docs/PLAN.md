# План

Цель: понять, какой метод обработки сигнала подходит для нашего стенда, идя от открытых датасетов похожих измерений.

| Шаг | Что | Результат |
|---|---|---|
| 1 | Подобрать датасет(ы), восстановить методику сбора | `docs/DATASETS.md` |
| 2 | Изучить данные: спектры, повторы, выбросы, дрейф | `reports/figures/` |
| 3 | Зафиксировать сплит (по группам) и метрики | `src/spectra/evaluate.py` |
| 4 | Сетка предобработка × модель (PLS, ridge, PCR, SVR, GPR, GBM; затем 1D-CNN) | `reports/*_results.csv` |
| 5 | Проверки устойчивости: без интерферента в train, другой день/партия, экстраполяция, размер выборки | таблица и графики |
| 6 | Дашборд + записка с рекомендацией для стенда | `reports/*_dashboard.html`, `reports/SUMMARY.md` |
| 7 | Требования к сбору данных на нашем стенде (концентрации, повторы, температура, кювета) | раздел в SUMMARY |

Метрики: RMSE (RMSEP), MAE, bias, R², RPD. Для глюкозы отдельно — сетка Кларка (если применимо).

Статус шагов 1–7 и дальнейшие задачи — в [`ROADMAP.md`](ROADMAP.md).
