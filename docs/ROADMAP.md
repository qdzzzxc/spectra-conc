## Отложенный прогон: TabPFN
Цель — понять, выигрывает ли предобученный трансформер у линейных моделей на тех же 5 фолдах.

Подготовка на новой машине:
```bash
uv sync --group nn
mkdir -p ~/.cache/tabpfn && cd ~/.cache/tabpfn
for f in config.json tabpfn-v3.5-20260909.safetensors; do
  curl -sSL -o "$f" "https://huggingface.co/Prior-Labs/tabpfn_3_5/resolve/main/$f"; done   # ~880 МБ
```
Прогон (`W='{"windows": "work"}'`; после задачи 010 добавить `--n-jobs 1`):
```bash
# 5 фолдов + экстраполяция, SNV и SG1(окно 51): ~15–25 мин на 2 ядрах без нагрузки
nice -n 19 uv run python -u scripts/run_experiment.py --loader ntnu --out reports/ntnu_tabpfn --models tabpfn --preps snv sg1w51 --loader-kwargs "$W" > reports/ntnu_tabpfn.log 2>&1
# устойчивость: ещё два разбиения
for s in 1 2; do nice -n 19 uv run python -u scripts/run_experiment.py --loader ntnu --out reports/ntnu_tabpfn_seed$s --seed $s --models tabpfn --preps snv sg1w51 --no-extrapolation --loader-kwargs "$W" > reports/ntnu_tabpfn_seed$s.log 2>&1; done
# внешняя валидация, интерференты, кривая обучения в сравнении с ridge
nice -n 19 uv run python -u scripts/run_ntnu_checks.py --out reports/ntnu_checks_tabpfn --pipes tabpfn:sg1w51 tabpfn:snv ridge:sg1w51 --quick > reports/ntnu_checks_tabpfn.log 2>&1
```
**Как читать результат** (правило 4 из `CLAUDE.md`): TabPFN лучше только если выигрыш больше разброса по фолдам (~0,9 мМ) и повторяется на seed 1 и 2 (разброс между seed у линейных моделей 0,02–0,07 мМ). Иначе — паритет. Смотреть ещё: ошибку на 50 мМ (экстраполяция), наклон по лактату/этанолу, время.
**Лицензия:** веса TabPFN v3.5 (`tabpfn-3-5-license-v1.0`) — только исследования и внутренние бенчмарки; коммерческое и продакшн-использование, включая решения по результатам, запрещено. Поэтому в рекомендацию для стенда TabPFN не попадёт, даже если выиграет; это записать в `SUMMARY.md` вместе с результатом.
После прогона: добавить строки в таблицу `SUMMARY.md`, абзац `tabpfn` в раздел «Нелинейные» в `METHODS.md`, пометку в «Что дальше» (вычеркнуть TabPFN), закоммитить.
