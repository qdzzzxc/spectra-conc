# Домен: коротко

- Объект: жидкость с растворённым веществом. Измеряем пропускание/поглощение/рассеяние света на разных длинах волн.
- Закон Бугера–Ламберта–Бера: A = ε·c·l, A = −log10(I/I0). Для смеси сигналы складываются: A(λ) = Σ εᵢ(λ)·cᵢ·l.
- Признаки: интенсивность (поглощение) по длинам волн; на дешёвом стенде — 3–10 LED + фотодиод.
- Методы: UV-Vis (200–800 нм), NIR (800–2500 нм), MIR/ATR (2,5–25 мкм), Raman (см⁻¹). Вода сильно поглощает в NIR/MIR.
- Мешающие факторы: температура, интерференты, дрейф лампы/детектора, пузырьки, рассеяние, положение кюветы, разные приборы.
- Предобработка: SNV, MSC, производные Савицкого–Голея, вычитание воды/опоры, отбор длин волн (iPLS, CARS).
- Данные: мало образцов, много коррелированных каналов, повторы одного раствора (группы), концентрации задаются планом эксперимента.
- Главные ошибки: утечка через повторы, случайный сплит по спектрам, оценка только внутри диапазона калибровки, один прибор/день.
